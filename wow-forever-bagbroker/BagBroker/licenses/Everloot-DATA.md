# Everloot data

`EverlootData.lua` contains drop observations from Everloot (https://everloot.app), the open,
player-built database for World of Warcraft: Forever.

Data from Everloot (https://everloot.app), CC BY-SA 4.0.
Licence: Creative Commons Attribution-ShareAlike 4.0 International,
https://creativecommons.org/licenses/by-sa/4.0/

BagBroker aggregates the published drop rollups per creature (loot windows and drops per item,
rates reported by at least two installs). Creative Commons declares CC BY-SA 4.0 one-way
compatible with GPLv3, so the combined database is distributed under GPLv3 with this attribution.
